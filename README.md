# Mimir – Менеджер режиму відновлення ОС

**Версія:** 1.0  
**Автор:** Slava  
**Платформа:** Windows 7/8/10/11 (x64)  
**Тип:** CLR .NET Framework (C++/CLI)

## 🔧 Можливості

- Перевірка статусу Recovery Environment (RE)
- Увімкнення / вимкнення RE
- Перезавантаження в режим відновлення
- Інтерфейс з кнопками, списком, виводом інформації
- Автоматичне підвищення прав до адміністратора

## 📦 Встановлення

1. Завантаж [інсталятор](#) або portable `.exe`
2. Запусти програму **від імені адміністратора** *(або програма сама перезапуститься з правами)*
3. Готово!

## ⚠️ Вимоги

- .NET Framework 4.7 або новіше
- Windows 7 і вище
- Адміністративні права

## 🛠 Команди, що використовуються:

- `reagentc /info`
- `reagentc /enable`
- `reagentc /disable`
- `shutdown /r /o /f /t 0`

## 📄 Ліцензія

Безкоштовне ПЗ. Поширення дозволено з вказанням автора.
